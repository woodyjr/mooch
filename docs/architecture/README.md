# Architecture Decisions

This folder stores architecture decision records (ADRs) for Mooch.

Use ADRs to capture decisions that are likely to come up again later, such as:

- technology choices
- authentication approach
- deployment strategy
- integration boundaries
- database design conventions

Current records:

- [ADR-001: Foundation Stack](./ADR-001-foundation-stack.md)

ADR format:

1. `Status`
2. `Date`
3. `Context`
4. `Decision`
5. `Consequences`
6. `Alternatives Considered`

When a future question comes up, prefer updating an existing ADR or adding a new one instead of burying the decision in chat history.
